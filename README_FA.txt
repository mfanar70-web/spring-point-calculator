# ابزار محاسبات نقاط فنرپیچی

## اجرا روی کامپیوتر شخصی

1. Python را نصب کنید.
2. فایل ZIP را از حالت فشرده خارج کنید.
3. در پوشه پروژه، پنجره CMD یا Terminal را باز کنید.
4. دستورهای زیر را اجرا کنید:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

5. مرورگر به‌صورت خودکار باز می‌شود. در صورت باز نشدن، این نشانی را وارد کنید:

`http://localhost:8501`

## استفاده با تلفن همراه در شبکه Wi-Fi یکسان

برای اجرای نسخه محلی روی کامپیوتر و باز کردن آن از گوشی، هر دو دستگاه باید به یک شبکه Wi-Fi متصل باشند. سپس در CMD اجرا کنید:

```bash
python -m streamlit run app.py --server.address 0.0.0.0
```

آدرس IP کامپیوتر را با دستور `ipconfig` پیدا کنید و در مرورگر گوشی وارد کنید:

`http://IP-COMPUTER:8501`

ممکن است لازم باشد دسترسی Python به شبکه خصوصی را در Windows Firewall مجاز کنید.

## لوگو

فایل `logo.png` در سربرگ برنامه استفاده می‌شود. برای تعویض لوگو، تصویر جدید را با همین نام جایگزین کنید.

## منطق محاسبه

تعداد نقاط شامل دو سر بازه است:

`گام = (حد بالا - حد پایین) / (تعداد نقاط - 1)`

این نسخه فقط نقاط با فاصله یکنواخت را تولید می‌کند؛ پروفیل واقعی فنر و محدودیت‌های کنترلی هر مدل دستگاه باید جداگانه بررسی شود.
